# UI指針メモ(蓄積中の傾向)

`SKILL.md`「デザイン方針(判断基準)」ほど確定していない、監修コメントから見えてきた傾向を書き留める場所。**義務的な振り返りではなく、該当する監修コメントが出たときだけ機会的に記入する**(→ `SKILL.md`「6. 指針メモを更新する」)。該当が無ければ何も書かなくてよい。

`pitfalls.md` との違い: `pitfalls.md` は実装上の技術的な罠(CSS詳細度・データ事故・Playwrightなど)、このファイルは**デザインの好み・傾向**(将来「デザイン方針」の判断基準になり得るもの)を扱う。

## 運用ルール

- 1エントリ = 1つの傾向。**その場の監修コメントから直接読み取れる範囲だけを書く**(推測で一般化しすぎない)。
- 同じ傾向が再度観測されたら、新規エントリを追加せず該当エントリの「観測」欄に日付を1件追記する。
- 観測が3件に達したエントリは見出しの先頭に🔺を付け、次にこのファイルを開いたタイミング(手順6)でユーザーに「デザイン方針への昇格」を提案する。**昇格するかどうかは常にユーザーが決める。Coordinatorが自動でSKILL.mdを書き換えることはしない。**
- 昇格して `SKILL.md`「デザイン方針」に反映したら、このファイルから該当エントリを削除する(同じ内容を二重管理しない)。
- 判断に迷ったとき、`SKILL.md`「デザイン方針」で決め切れない細部の参考にしてよい。ただしここに書かれているのは**確定した原則ではなく傾向**なので、既存デザイン方針の禁止事項(新しいデザインを作らない等)と矛盾する内容には使わない。

## 記入フォーマット

```markdown
### <傾向の要約(1文)>
- 観測: 2026-08-20(対象: box/damage 詳細設定モーダル)
- 監修コメントの要旨: 「...」
```
