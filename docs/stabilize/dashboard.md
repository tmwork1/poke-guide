# 描画安定性(揺れ)ダッシュボード

`stabilize` skill(`/stabilize`)の**唯一の状態保存先**。計測したら該当行を更新する。

計測条件は既定で **`--size 390x844 --theme dark --repeat 3`**(モバイル専用方針・ダーク一本化のため)。対象の一覧と probe コマンドは `.claude/skills/stabilize/references/targets.md`。

## 判定基準(2つ。どちらか一方でも外れたら不合格)

| 指標 | 🟢 | 🟡 | 🔴 |
|---|---|---|---|
| フェーズ合計 `totalAll`(中央値) | < 0.01 | 0.01 〜 0.05 | ≥ 0.05 |
| 個別シフトの最大移動量(px) | < 2 | 2 〜 4 | ≥ 4 |

**スコアだけで判定しない。** 小さい要素が起こす揺れは `value` が 0.00 と出るのに目にははっきり見える(例: 技タイプバーが技名を6px押す)。移動量が 4px 以上なら🔴。

## 既知の課題・対応履歴

### 対応済み

- **技タイプ色バーが後から出て技名が3〜6px右へずれる**(2026-09-10、パターンA)。`[hidden] { display: none }` で幅0→3pxになっていたのをやめ、常に幅を占めさせて `background-color: transparent` で未解決を表す。box一覧カード・プレビュー・チームカード・ダメージ計算カード・候補・詳細パネル・上位チームカードの7箇所。**CLSスコアでは 0.00 と出るのに目にははっきり見える**典型例
- **チーム編成の「登録中…」がボタンの中身を丸ごと差し替えて幅を変える**(2026-09-10、パターンB)。文言差し替えを廃止し `disabled` だけにした
- **上位チームカードの技タイプ画像に表示寸法が無く、読み込み完了まで高さが確定しない**(2026-09-10、パターンD)
- **`/box/<id>` の保存状態(`#autosave-status`)をJSが `#mobile-edit-actions` へDOMごと移設していた**(2026-09-10、パターンF)。移設をやめ、最終表示位置にSSRするようにした。CLS 0.17→0.07
- **`/box/<id>` の実数値・残り努力値が空→数値で幅が伸びる**(2026-09-10、パターンC)。桁数ぶんの `min-width` と `tabular-nums` で予約
- **`/team/<id>` のポケモンカードの実数値18セルを非同期計算の完了後に追加していた**(2026-09-10、パターンC)。セルを先に置き、計算待ちは `visibility: hidden` にした。技一覧が41px上へ動く揺れが消えた

### 未対応(原因の切り分けまで済んでいるもの)

- **`/box/<id>` `/box/new` の `.edit-layout-training` が ±52.6px / ±28.2px 動く。** `--cls` の全source表示で、動いているのはポケモンプレビューの中身(`ol.pokemon-preview-moves` dh=+36.6、`#pokemon-preview-stats-trigger` dh=+21、`#pokemon-preview-ability` dy=-72.8)と判明。**`--no-js` で開くと CLS 0 で、しかも最終レイアウトはJS有無で完全に一致する**ので、SSRの寸法は正しく、JSが一度プレビューを作り直しているだけ。`MobilePokemonPreview.astro` の `<script>` に「育成タブでは直後にpokemon-edit-panel.tsのフォーム同期が上書きする(想定内・害はない)」とあるとおり、この上書きが犯人。SSR済みの値と同じなら書き換えないようにするのが筋
- **`/team/<id>` の `.panel-content` が 8px 縮む**(dy=+8 dh=-8)。未調査

## 計測時の注意

- **1回目の計測は dev server の初回コンパイルで極端に悪く出る。** 必ず `--repeat 3` の中央値で判定する
- **OP.GG使用率は dev では空になる**(→ `project_opgg_usage_dev_server_stall`)。使用率が絡む揺れは `npm run preview` で測る
- **dev server は認証をバイパスする。** 未ログイン/ゲストの揺れは `npm run preview` か `--guest` で測る
- **`--click` 等の操作オプションは自動保存を誘発して実データを壊しうる。** `.claude/skills/ui/references/pitfalls.md` を読んでから使う
