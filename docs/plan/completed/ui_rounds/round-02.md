## ラウンド2の指摘(2026-07-26 opusアドバイザー講評: ボックス一覧 `/box`)

ラウンド1の改修後、1920×1080でライト/ダーク・ホバー・検索0件・ピン留め・20体時の密度まで実測して得た指摘。実測値: カード312×513px、グリッド5列(1624px)、**20体時に1画面に見えるカードは4枚**。

### 優先度A(必ず直す)
- **A-1 ピン留めカードが「無効化」に見える**: `.is-pinned` が `--color-warning`(#aaaaaa)を使っており、エース個体だけ灰色に沈んで disabled に見える。★ボタンも押せないボタンに見える。→ 既存の `--color-risky`(#c9820f / dark #e0a940)へ差し替え。新色は作らない。
- **A-2 カード513pxは高すぎる**: フルHDの1画面に4体しか収まらず「一覧」として機能しない。→ **430px以下**を目標(174 + 430×2 + gap16 = 1050 ≤ 1080 で2行が必ず収まる)。削り方: `.card-art` を高さ110px・絵を104pxに(空白40pxを削りつつ絵は大きくする)/ニックネームを種族名の右に併記して1行削る/`.card-ev-heading` を廃止(A-3で行ラベル化)/padding と gap を1段階詰める/技行の line-height 1.6→1.35。**列数5列は維持**(横を詰めると実数値の桁が崩れる)。縦を削るのが正解。
- **A-3 努力値/実数値の2段グリッドの階層が逆転**: より重要な実数値が小さく淡い。どちらの行かも推測頼り。→ ダメージ計算カードと同じ**「行ラベル1列 + HABCDS の7列グリッド」**(第3弾で確立済みの構造)に統一。DOMは**行優先**(見出し7セル→実数値7セル→努力値7セル)。実数値を 0.92em・通常色で主、努力値を 0.74em・muted で従に。**努力値の0は `0` ではなく中黒 `·`**。行ラベルは「実数」「努力」。列そのものは6列維持(配分を形で読むため)。
- **A-4 実数値の色**: `#1d6fd1` がハードコードされ、ダークのカード背景に対しコントラスト約2.7:1でWCAG AA割れ。かつ性格補正が**色のみ**で伝わる(WCAG 1.4.1)。→ ページscopedで `--card-stat-down` を変数化しダーク側を `#6fb6f7` に。加えて `box/[id].astro` にある `.stat-mod-arrow[data-mod]` と同じ**▲▼を0.7emで実数値に添える**。凡例は置かない(A-5で性格名を出せば自明になる)。赤=上昇/青=下降は本編準拠なので色自体は変えない。**同じ `#1d6fd1` が `box/[id].astro` にも3箇所ある(タスクC側で同修正)**。
- **A-5 特性・性格がカードに無い**: 特性は持ち物と同格以上の識別情報で、しかも `matchesSearch()` は `ability_name` を検索対象に含めており「検索できるが表示されない」状態。→ 種族名の直下に1行のメタ行(`いじっぱり ・ かたいツメ`、0.78em muted、1行省略)。レベルは常時50なので出さない。
- **A-6 タイプが第1タイプしか出ていない**: `applyCardTypeBadge()` が `types?.[0]` しか見ておらず、メガリザードンX(ほのお/ドラゴン)が FIRE のみ。情報として不正確。→ `types` 全件をループしてバッジを並べる。

### 優先度B
- **B-1 空技スロットの「-」縦4連**がデータ破損に見える。→ 高さ固定は `.card-moves { min-height: calc(4 * 1.35em) }` で達成し、**未設定スロットのDOMは出さない**。0件時のみ中央に淡色で「技未設定」を1回。スロット感を残すなら `-` ではなく淡い1px dashed の下線。
- **B-2 ツールバーの右半分が空**(バー1624pxに対し中身780px)。→ 検索欄を `flex: 1 1 320px` で伸ばし、並べ替えを `margin-left: auto` で右端へ。「検索(左)—絞り込み(中)—並べ替え(右)」。
- **B-3 追加タイルが513pxの空洞・検索0件時は130pxに縮む**(同じ要素の高さが4倍変わる)。→ 破線を 2px→1px に落とす/`＋` を円形プレースホルダ(56px)にする/ラベル下に補足1行/`min-height: 260px` で下限を作る/ホバーに `background: var(--color-primary-soft)`。位置(グリッド先頭)は維持。
- **B-4 未ピンの☆が全カード右上に常時4個浮いている**。→ 🗑 と同じく `@media (hover:hover) and (pointer:fine)` で未ピン時のみ非表示。**ピン留め済みの★は状態表示なので常時可視**。
- **B-5 ダークでタイプバッジが沈む**(あく/ゴーストが背景に溶ける)。→ ダーク時のみ `.card-type-chip` に `background: rgba(255,255,255,0.08)` の下敷き。
- **B-6 公式絵が小さい**(312px幅のカードに92px)。→ A-2と同時に枠110px・絵104pxへ。
- **B-7 テラスの「テラス」テキストラベル**がカード上で唯一の項目ラベルで浮いている。→ 記号区切り(`/`)か枠線で区別する。
- **B-8 カード内で整列が4回変わる**(中央→左→中央)。→ 区切り線より下は左揃えに統一(種族名も左)。数値グリッドのセルは中央のままでよい。
- **B-9 検索0件時の表示が壊れている**: メッセージが縮んだ追加タイルの右横に宙に浮く。件数バッジも「4体」のまま矛盾。→ 空状態カードと同じ見た目に揃え、件数バッジを絞り込みに追随(`2 / 4体`)。

### 優先度C(要判断)
- C-1 「検索」ラベルは虫眼鏡+placeholderで自明なので `sr-only` 化して幅を回してもよい(「絞り込み」「並べ替え」は残す)。
- C-2 努力値ミニバーの空トラックがモード間で見え方が違う。→ `ev > 0` のときだけバーDOMを出す。残す場合は空トラック色を明示。H=4は `min-width: 4px`。
- C-3 4体時に下半分が空くのは**許容**(増える前提の画面)。A-2で2行収まる高さにすれば印象は改善。埋めるならツールバー右端に総数・エース数サマリ。
- C-4 トーン: 現状は「図鑑・コレクション」寄り。色を変えず (1)数値のウェイト向上(A-3) (2)縦リズムを詰める(A-2) (3)整列統一(B-8) の3つで「対戦ツール(作業台)」側に寄る。`編集 >` のような矢印は不要。
- C-5 カード `<a>` のアクセシブルネームが数値の羅列を読み上げる。`aria-label` 付与を検討。
- C-6 追加タイルの先頭固定はワイヤーフレーム準拠なので**維持**。

### 維持すべき点(壊さないこと)
カード高さが完全に揃っている原則 / タイプバッジがスプライトに重ならない分離 / 🗑 のホバー表示+タッチ端末除外 / 実数値をPyodideなしで純JS計算(IV=31・Lv50前提)/ 公式絵のフォルム対応(`imageId` 解決)/ `.card-interactive` のホバー持ち上がり(reduced-motion対応込み)/ `.box-shell { max-width: 1760px }` で1920pxちょうど5列。
