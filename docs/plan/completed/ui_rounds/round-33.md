### 要件

- **33-S1**(← U-1、出典 round-09.md B-5。**10ラウンド以上滞留していた**)
  > ユーザーの回答: **「DOMごと削除」**

  `src/pages/search/index.astro` の「**最近注目されているもの**」セクション(`section.panel` > `.panel-content` > `h2`、61〜62行目付近)を**DOMごと削除する**。
  - このセクションは `GET /api/suggestions?kind=trending_search` の結果を表示する枠だが、**常に空**のまま10ラウンド以上放置されていた(ラウンド9で発見)。
  - **⚠️ このラウンドは例外的に「DOMを残してCSSで見せない」方針を採らない。** 通常の要件では `pitfalls.md`「要素を『消す』指示が来ても、DOMは残してCSSで見せない」に従うが、**今回はユーザーが明示的に「DOMごと削除」を選んだ**ため。
  - **API エンドポイント(`/api/suggestions`)とサーバー側の実装は削除しないこと。** 他のページから使われている可能性があるので、**先に `src/` 全体を grep して、この kind (`trending_search`) と `/api/suggestions` の参照箇所を洗い出し、`/search` からしか呼ばれていないと確認できた分だけ**クライアント側の fetch 処理を削除する。**確認結果を報告すること**(他ページから参照があるなら API 呼び出しは残す)。
  - 削除後、**ページ下部に不自然な空白が残らないこと**(セクションが1つ減るので、残りのセクションの余白が破綻しないか実測する)。

- **33-G1**(← U-2、出典 round-12.md C-2)
  > ユーザーの回答: **「接頭辞を削除」**(メールアドレスだけ表示。移設先がログアウトボタンの真上なので文脈で伝わる)

  `src/components/AppSidebar.astro:91` の
  ```astro
  <span class="app-sidebar-account-email">ログイン中: {user.email ?? user.displayName ?? user.id}</span>
  ```
  から **「ログイン中: 」の接頭辞を削除**し、メールアドレス(またはフォールバック値)だけを表示する。
  - **⚠️ これは全ページ共通のサイドバーなので、全ページに波及する。**
  - **`app-sidebar-account-email` クラスは改名しないこと**(`global.css` に `.app-sidebar-account-email` / `.app-topbar-account-desktop` 系の指定があり、モバイルでの二重表示を防ぐ打ち消しが絡んでいる。→ `pitfalls.md`「`global.css` の指定が Astro の scoped style に詳細度で負ける」の実例そのものの箇所)
  - **スクリーンリーダー利用者に「これがログイン中のアカウントである」ことが伝わる手段を残すこと**(可視ラベルを削るので、`aria-label` かそれに相当する手段を検討する。**視覚的に消しても読み上げ情報は落とさない**というのがこのプロジェクトの既定方針 → 28-R9 の「その他の状態」ラベルの扱いが先例)。
  - メールアドレスが長い場合に省略されるか、レイアウトが崩れないかを確認すること(現在の表示は `dev@localhost`)。

### 運用面での収穫(`SKILL.md` Step -1 の初回適用)

**worktree運用を実際に立ち上げて、手順書に3つの穴が見つかった。すべて `SKILL.md` Step -1 と `pitfalls.md` に反映済み。**

### 実装エージェントの危険な操作(是正済み)

- **実装者が削除前後の空白を比較するために `git stash` を使った。** **stashスタックはリポジトリ全体で共有されており、他のworktree・他セッションのstashを巻き込む/横取りする危険がある**(このセッションはまさに「別プロセスがコミットして事故った」直後だった)。結果的に `git stash list` は空で残骸なし・実害なしだったが、**`agent-prompts.md` の実装者テンプレートに「`git stash` を使わないこと」と代替手段(変更前の値を先に実測する / `.tmp-*` にコピーを退避する)を明記した。**
