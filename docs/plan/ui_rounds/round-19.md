## ラウンド19の位置づけ(2026-07-27)

**新しい講評は行わない。** ラウンド18の調査で判明した**最優先の表示バグ**を直し、あわせて溜まっていた優先度Cのうち「判断が要らない小粒なもの」を片付ける。

### 最優先: 威力が固定値でない攻撃技14件が `/box/[id]` で「ダメージ0」と表示される

**調査結果は `docs/plan/ui_rounds/round-18.md` の「次ラウンド(19)に回すもの」に記録済み。** 要点:

- `power: null` かつ変化技でない技は **14件**: `いかりのまえば` / `いのちがけ` / **`カウンター`** / `がむしゃら` / `じわれ` / `ぜったいれいど` / **`ちきゅうなげ`** / `つのドリル` / **`ナイトヘッド`** / `はきだす` / `ハサミギロチン` / `ほうふく` / **`ミラーコート`** / `メタルバースト`
- `/box/[id]` のダメージ計算(`calc_lethal` 経路)では**これらが特別扱いされず、威力nullがそのままダメージ0**になる(`vendor/jpoke/src/jpoke/core/lethal.py` と `core/damage.py` に `ohko` の参照が0件)。結果、**「10発以上」「累計0〜0 (0%)」**と表示される。
- **対戦で普通に使う技が「まったくダメージが出ない技」に見える。** カウンターやちきゅうなげを設定したプレイヤーが「この技は無意味」と誤解しうる。
- **`/moves/[name]` では既に正しく扱えている**(`src/pages/moves/[name].astro:246`):
  > この技は威力が固定値ではなく特殊な計算式(相手の残りHPや受けたダメージ量など)で決まるため、期待値は算出できません。
  **この語彙を `/box/[id]` に移植する。**

### Coordinatorの判断: 優先度Cのうち、扱うもの・扱わないもの

**扱う(判断が要らず、実害があるもの)**:
- `/moves/[name]` で **`わるあがき`(タイプ無し技)にも「複合タイプは掛け合わせ/テラスタル」の注記が出る**(→ round-16.md 積み残し)。同じ画面に「常に等倍」と書いてあるので**明らかに不要な情報**。1行の条件追加で消える。
- `/box/[id]` の**多段ヒット技のヒット数入力に、既定値が最小保証回数である理由が無い**(→ round-17.md 優先度C)。`title` に一言足すだけ。
- `/box/[id]` に残る **`STAT_KEYS` のローカル再定義**を `src/lib/stats.ts` に寄せる(→ round-18.md 積み残し)。

**扱わない(理由を明記して再提起を止める)**:
- **`H A B C D S` と ▲▼ の凡例**: UXレビュアー自身が「対戦経験者が主対象」「常時表示するとラウンド12 B-2で見出しを0.64emに留めた判断と衝突する」と書いており、その通り。**確N/乱N/未撃破の凡例(ラウンド17 A-5)とは略語の難易度が違う**ため、そちらだけ実施済みで十分。**再提起しない。**
- **「残り18」に上限66の分母が無い件**: **ラウンド3 B-7で削除 → ラウンド5で「残り」として復活**という経緯があり、510ルールとの誤連想を避けるための意図的判断。**同じ論点を3度目に触るのはユーザー判断が要る。** 積み残しに残す。
- **ピン留め(エース)と危険度チップが同じ `--color-risky` を共有している件**: ピン留めは `/box`、危険度チップは `/box/[id]` にあり、**同じ画面に同時に出ることがない**。色の意味が衝突して見える場面が実際には存在しないため**現状維持**。**再提起しない。**
- **種族選択ボックス右上の15pxアイコン**: UIレビュアー自身が「視認性を損なうほどではない、修正の緊急性は低い」と書いている。積み残しに残す。

**ユーザー指示により、このラウンドでUI改善ループを終了する。** sonnetサブエージェント2体で実装。**下記はCoordinatorが自分で実測して確認した値。**

| 項目 | 結果(Coordinator実測) |

| **威力null技14件の表示**(最優先) | 「0ダメージ・10発以上・0%」→ **理由の説明に置き換わった**。カウンターで「威力が固定値ではなく特殊な計算式(相手の残りHPや受けたダメージ量など)で決まるため、ダメージを算出できません。」を確認 |

### 実装者がCoordinatorの誤りを訂正した件(記録)

Coordinatorの指示に「**変化技(まもる等)は既に『変化技なので〜』の扱いがあるはず**」と書いたが、**実装者が実際に調べたところ `/box/[id]` にそのような専用表示は存在しなかった**(`/moves/[name]` の技詳細ツールチップが分類ラベルを出すだけ)。実装者は `category !== "status"` で変化技を明示的に除外し、**既存の挙動を一切変えていないこと**をPlaywrightで確認して報告した。**指示の前提を鵜呑みにせず検証した good example。**

## 積み残し(ループ終了時点)

### すぐ着手できるもの
- **変化技(`まもる` 等)が `/box/[id]` で「10発以上 0 (0%)」と表示される。** 変化技のダメージが0なのは事実だが、「10発以上」という表現が誤解を招くかは別論点。**今回は意図的にスコープ外**(status除外により無変更)。
- **カード合計の「算出不能技を含む」断り書きがやや長い。** 専用アイコン等で目立たせる余地はあるが、既存の2分割表示(verdict/detail)の枠内に収めてある。
- **`/moves` の変化技は下部に約534pxの空白が残る**(情報量自体を増やさない限り解けない)。
- `/pokemon` 識別ブロックの3項目で箇条書きの有無が不統一、「値が無い」ことを示す語彙が4種類併存(→ round-15.md 優先度C)。
- 種族選択ボックス右上の15pxアイコンが同ページ最小(→ round-17.md 優先度C)。
