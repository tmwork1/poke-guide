## 設計レビュー(2026-08-14)

codex(`--sandbox read-only`)によるレビューで、当初案の前提が崩れる指摘(優先度A)が3件見つかった。いずれも採用し、以下の「スコープ内」「受け入れ基準」に反映済み。

### 採用した指摘

- **A-1 ホームへの導線がほとんどのページで機能しない**: 【問題】ホームカードの遷移先5ページのうち `/box` `/team` `/data` `/ranked-teams` の4つは `AppLayout` を `hideTopbar={true}` で呼んでおり、共通トップバー自体(ブランド行を含む)が描画されない。トップバーのブランド名を「ポケガイド」にしてリンク化しても、この4ページではDOMごと存在しないため機能しない。 → 【対応】`AppBottomNav.astro` に5番目の項目「ホーム」(`href="/"`)を追加し、`hideTopbar` の状態に関わらずどのページからも `/` に戻れるようにする。トップバーのブランドリンク化は維持するが、あくまで「トップバーを描画しているページでの補助的な導線」の位置づけに変更する。
- **A-2 ホーム画面自身のブランド表示が二重になる**: 【問題】ホーム画面の `AppLayout` 呼び出しで `hideTopbar` の指定に触れていなかったため、既定値 `false` のままだと共通トップバーの「ポケガイド」表示と、ワイヤーフレーム本文の「ロゴ・アプリ名」セクションが上下に二重表示される。 → 【対応】ホーム画面も他の一覧系ページ(`/box` 等)と同様に `hideTopbar={true}` で呼ぶ。
- **A-3 ログアウトを `<a href>` にすると405になる**: 【問題】`/api/auth/logout`(`src/pages/api/auth/logout.ts`)はPOST専用で、単純なリンクはGETになり `Method Not Allowed` を返す。 → 【対応】`<form method="post" action="/api/auth/logout">` + 送信ボタン(見た目は既存のリンク/ボタンスタイルに揃える)にする。
- **B-1 カードグリッドの列数指定が抜けていた**: 【問題】ワイヤーフレームは2列×3行の固定グリッドだが、既存の `.card-grid`(`auto-fill, minmax(240px,1fr)`)を375px幅で流用すると1列(縦積み)になる。 → 【対応】ホーム専用CSS(`src/styles/home-page.css`)で `grid-template-columns: repeat(2, 1fr)` を明示する。
- **B-2 アイコンの不足**: 【問題】6カード中「ダメージ計算」「上位チーム」用のアイコンが既存コードに無い。 → 【対応】ボックス/チーム/バトルデータ/すばやさの4つは `AppBottomNav.astro` の既存インラインSVGを流用し、残り2つ(ダメージ計算=電卓、上位チーム=トロフィー)は同スタイル(stroke系・`viewBox 24x24`・`stroke-width 2.05`)で新規に用意する。
- **B-3 ダメージ計算カードの説明文**: 【問題】遷移先の `/box` はカードグリッド+検索ツールバーで、ダメージ計算らしさがどこにも現れない。 → 【対応】説明文を「ポケモンを選ぶとダメージ計算に進めます」のように、他5枚と違い遷移後にもう1段操作が要ることが分かる文言にする。
- **B-4 「Poke-Commons」表記の残存**: 【問題】コード内コメントや計画書中に「Poke-Commons」表記が他にも残っている。 → 【対応】今回のスコープでは追わない(下記スコープ外に明記)。

### 却下・保留した指摘

- **C-1 ワイヤーフレーム上部の戻る矢印**: ホーム(サイト最上位)には戻り先が無いため、`backHref` は指定しない(既存の「未指定なら非表示」という `AppLayout` の挙動どおり)。ワイヤーフレームの矢印は共通テンプレート由来の描き込みと判断し、ユーザーには確認しない(この判断で実装が変わる論点ではないため)。
- **C-2 「カード」という用語の厳密な当てはめ**: 固定6項目のメニューは `00-foundation.md` の「可算コレクション」定義に厳密には合わないが、視覚仕様の踏襲に実害は無いため指摘のみ記録し、対応はしない。
- **C-3 `stack.md` の `AppSidebar` 案内が古い**: 実装者向けの注意として下記「確定した設計」に明記するのみ(`stack.md` 自体の修正はこのページのスコープ外)。

### 確定した設計

- ホーム画面の `AppLayout` は `hideTopbar={true}` で呼ぶ。
- `AppBottomNav.astro` に5番目の項目「ホーム」(`href="/"`)を追加する。`current` 型は `AppLayout`/`AppBottomNav` 両方に `"home"` を追加。
- ログアウトはPOSTフォーム送信にする(`<a href>` は使わない)。
- カードグリッドはホーム専用CSS(`src/styles/home-page.css`)で2列固定にする(既存 `.card-grid` は流用しない)。
- ダメージ計算・上位チームのアイコンは新規SVGを用意する(既存4アイコンは `AppBottomNav.astro` から流用)。
- **実装時の注意**: `AppSidebar.astro` は現存しない(`references/stack.md` の記述は古い)。ナビゲーション関連で触るのは `AppBottomNav.astro` と `AppLayout.astro` のみ。
